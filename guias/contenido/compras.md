# Compras

## Para qué sirve

Revisa las facturas de compras y decide cuáles corresponden a tu operación. Usa el módulo cuando recibas una factura o necesites distribuirla entre locales.

## Paso a paso

1. Entra a **Compras** y abre **Módulo principal** para revisar las facturas pendientes.
2. Selecciona una factura para ver su detalle. Comprueba proveedor, valores y el local al que corresponde.
3. Si aplica a más de un local, revisa **Distribuir locales** antes del envío.
4. Usa **Enviar** cuando el detalle esté correcto. Si no corresponde a tu negocio, usa **No corresponde**.
5. Consulta **Revisadas** para comprobar lo que ya trataste.

## Si algo no sale bien

- Si un botón está deshabilitado, selecciona primero una factura y completa la revisión requerida.
- Si clasificaste una factura en **No corresponde**, consulta esa pestaña antes de duplicar el trámite.
